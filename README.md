# README #

### Ultrazom Temperature Measurement Card ###
This digital sensor card allows the Ultrazohm to measure up to 60 multisensor temperature Channel, of which 40 can be accessed directly on the front panel of the Ultrazohm.
This card is still in development, so please be carefull if you create your own Version of this card!
